# Shatter Frontend

React + TypeScript + Vite UI for the Shatter CNC platform.

**Setup and UX:** [Development Guide](../docs/DEVELOPMENT_GUIDE.md), [UX Design Guide](../docs/UX_DESIGN_GUIDE.md), [User Guide](../docs/USER_GUIDE.md).

```bash
# From repo root (recommended)
docker compose -f docker-compose.dev.yml up -d

# Or local dev server
cd frontend && npm install && npm run dev
```
