SHATTER INSTALL KIT
==================

Do this

  1. Install Docker and Komodo.
  2. Create a Stack in Komodo.
  3. Generate .env + docker-compose.yml and paste them into the Stack.
  4. Deploy.
  5. Installation guide · Support

1) Choose OS

Select your OS.

2) Install Komodo

Follow: https://komo.do/docs/setup/mongo

Komodo UI will be at http://<host>:9120.

Komodo is where you will manage Shatter as a service: deploy, restart, update images, view logs, and monitor health.

3) Create a Stack in Komodo

In Komodo, create a new Stack for Shatter.
You’ll paste the generated .env and docker-compose.yml into this Stack in later steps.

4) Create a Postgres password

Pick a strong password. You will need it if you move/restore the database.

5) Generate key

Security: this page never uploads your secrets. It only generates text locally.

6) .env

Copy to clipboard to proceed.

In Komodo (in your Stack): paste or upload this as the Stack .env.

7) Optional: MQTT publishing

Shatter can publish full retained snapshots to Mosquitto. You can skip this step and configure MQTT later by editing the compose/env directly.

If you enable MQTT here, the generator will include a mosquitto service and backend MQTT_PUBLISH_* env vars.

8) docker-compose.yml

Copy to clipboard to proceed.

In Komodo (in your Stack): paste this as the Stack compose file (docker-compose.yml).

9) Deploy

  1. Deploy the Stack.
  2. Wait for all services to be healthy/running.
  3. Open the Shatter UI at http://<host>.
  4. Backend health: http://<host>:8000/health
Optional: automatic updates
If you want this Stack to auto-update when new images are published:
  1. Keep using the latest tag.
  2. Enable Komodo auto-redeploy / sync-on-change (if available in your Komodo version).
  3. Or schedule a periodic redeploy (for example daily) to pull the newest images.
